# MindGuard v1.0.0 — Release Notes

## 🎉 First Production Release

MindGuard Desktop Companion v1.0.0 is the first production-grade release of our attention operating system's desktop companion.

### What's Included

**MindGuard Setup.exe** — Full NSIS installer with:
- Custom installer banner with MindGuard branding
- Choose installation directory
- Desktop shortcut creation
- Start menu shortcut creation
- Uninstaller included

**MindGuard Portable.exe** — Zero-install portable version:
- No installation required
- Run directly from any folder
- Settings stored alongside executable
- Perfect for USB drives or shared computers

### Features

- 🔒 **Attention Protection** — Real-time monitoring of your digital habits
- 🧠 **AI-Powered Insights** — Understand your patterns, best coding hours, and distractions
- ⏱️ **Focus Timer Sync** — Desktop timer seamlessly syncs with web dashboard
- 📊 **Activity Timeline** — Every digital event recorded chronologically
- 🔔 **Smart Notifications** — Idle reminders, break alerts, and focus celebrations
- 🔄 **Offline Support** — Works without internet, syncs when connected
- 🛡️ **Privacy-First** — No passwords, form data, or private content captured
- ⚡ **Lightweight** — <1% CPU, <100MB RAM, <2s startup

### System Requirements

- Windows 10 or later (x64)
- 100MB free disk space
- Internet connection for sync (optional — offline supported)

### Installation

1. Download **MindGuard-Setup-1.0.0.exe** for full installation
2. Or download **MindGuard-Portable-1.0.0.exe** for portable use
3. Follow the installer prompts (or just run the portable exe)
4. MindGuard will start automatically and appear in your system tray

### Auto Updates

MindGuard will automatically check for updates and notify you when a new version is available. Updates download in the background and install on next restart.
